## 生成为什么慢？

视频与 Canvas 流水线属于耗时任务，可能需要几十秒到数分钟。任务排队、模型负载都会影响时长。Pro 及以上套餐享有优先队列。

## 生成失败怎么办？

失败任务**不扣费**（除非部分成功）。你可以：

- 查看失败原因（任务详情会展示分类后的错误）。
- 一键重试。
- 调整参数后重新提交。

详见 [计费说明](/docs/billing)。

## 余额不足会怎样？

余额不足时无法提交新任务；已在运行的任务不受影响。系统支持低余额提醒。充值或购买套餐后立即恢复。

## 结果不满意能退吗？

生成结果本身不构成「可退货商品」，但因平台原因导致的失败会自动退款 / 补偿。详见[计费说明](/docs/billing)。

## 结果可以商用吗？

可以。生成结果可用于商业用途，但你需对使用场景与合规性负责。详见[商用说明](/docs/legal/commercial-use)与[内容政策](/legal/content-policy)。

## 数据保存多久？

上传与生成内容默认长期保留，可在资产库随时删除。企业版可配置自定义留存策略。

## 提供 API 吗？

提供，兼容 OpenAI 协议。详见 [API 鉴权](/docs/api/authentication)。
