工作台是你进行日常创作的核心界面。

## 能力切换

顶部切换文本 / 图片 / 视频 / 字幕四大能力。切换能力后，参数面板与模型列表会自动更新到该能力下的推荐配置。

## 参数编辑

- 文本：system / prompt、温度、生成长度。
- 图片：提示词、尺寸、张数（`n`）、风格。
- 视频：提示词或参考图、分辨率（720P / 1080P）、时长。
- 字幕：上传视频、字幕样式预设。

## 提交与状态

提交后任务进入统一队列，状态依次为：排队 → 运行中 → 成功 / 失败 / 已取消。任务进度通过实时事件（SSE）推送到界面，无需手动刷新。

失败的任务可以一键重试或取消，详见 [Canvas 任务恢复](/docs/canvas)。

## 实时同步

工作台通过 SSE 订阅任务事件：完成、失败、余额变化都会实时反映。Token 仅存内存，浏览器请求走 httpOnly cookie。
