Excuse 采用基于**积分（credit）**的统一计费。所有能力的消耗都折算成积分，放在同一个账户里管理。

## 计费单元

| 能力 | 方式 | 说明 |
| --- | --- | --- |
| 文本 | 按 token | 输入 + 输出 token 各按 1M 单价计 |
| 图片 | 按张数 | 尊重 `n`，出几张算几张 |
| 视频 | 按时长 | 720P / 1080P 单价不同 |
| 字幕 | 按音频时长 | ASR 转写成本 |

> 价格基于整数分（cents）做算术，金额是派生显示，避免浮点误差。

## 生成前预估

提交任务前，工作台给出**本次积分预估**，帮你避免误用昂贵配置。

## 失败计费规则（重要）

- 内容审核失败、供应商异常：**不扣费**。
- 部分成功：只计入成功部分。
- 平台侧问题：自动补偿或退款。

## 账本

所有扣费、充值、赠送、退款、人工调账都写入统一账本（reserve → debit / refund），保留审计痕迹。计费页面提供按类别 / 模型拆分的统计与 30 天趋势。

## 套餐与运营

支持免费额度、积分包、订阅、赠送额度（含有效期）、优惠码、低余额提醒等运营能力。详见[定价](/pricing)。
