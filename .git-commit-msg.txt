feat(worker): media processing taskification — audio extraction & subtitle burn as unified tasks

Move subtitle pipeline media operations into the unified task system (P4.2):

- New `media.extract-audio` task: server creates task instead of synchronous ffmpeg call (was blocking HTTP request). Worker handles audio extraction, upload, ASR submission, and generation_record creation.
- New `media.burn-subtitle` task: replaces the separate `pollExportingProjects` loop. Worker burns subtitles via ffmpeg, uploads result, updates project status.
- Refactored `apps/server/src/modules/subtitle/service.ts`: `createAndStartProject` now creates a task and returns immediately. `retryProject` creates a task for the no-progress path.
- `apps/worker/src/task-handler.ts`: registered both new handler types.
- Cleaned up: removed `processExportTask` from `subtitle-processor.ts`, removed `pollExportingProjects` from worker main loop.
- New `apps/worker/src/media-handlers.ts` with `handleMediaExtractAudio` and `handleMediaBurnSubtitle`.
- New `apps/worker/test/media-handlers.test.ts` (6 tests) + updated subtitle-processor tests.
- Fixed test isolation: added `--isolate` flag for worker tests to prevent mock.module conflicts.
- ESLint import ordering fixes across client pages.
