1. 认证与账户管理

用户注册 / 登录 / 登出 已实现

邮箱+密码注册、登录、登出，支持 JWT Bearer Token + httpOnly Cookie 双通道认证。

  • POST /api/auth/register — 注册（用户名 3-50 字符，密码 6-100 字符，bcrypt 哈希）
  • POST /api/auth/login — 登录（含禁用账户检测 + 审计日志记录 IP）
  • POST /api/auth/logout — 登出（清除 httpOnly cookie）
  • GET /api/auth/me — 获取当前用户信息
  • Cookie 配置：httpOnly + secure + sameSite=lax，7 天有效期
  • 前端组件：Login.tsx、Register.tsx、AuthContext.tsx、ProtectedRoute.tsx
🤖

2. AI 内容生成（Workspace 工作台）

2.1 多模型文本生成 已实现

选择文本模型 → 输入 Prompt + 参数 → 发起生成 → 实时查看结果，支持 5 个千问系列模型。

  • qwen-max — 千问 Max（240/960 分/百万 token）
  • qwen-plus — 千问 Plus（80/200 分/百万 token）
  • qwen-turbo — 千问 Turbo（30/60 分/百万 token）
  • qwen-long — 千问 Long（50/200 分/百万 token）
  • qwen3.7-plus — 千问 3.7 Plus（160/640 分/百万 token，OpenAI Chat 协议）
  • POST /api/generate — 发起生成
  • GET /api/records — 查询记录（按 category/status 过滤）
  • GET /api/records/:id — 单条详情
  • DELETE /api/records/:id — 删除记录
  • POST /api/records/:id/retry — 重试失败任务
  • POST /api/records/:id/cancel — 取消进行中任务
  • GET /api/models — 获取所有模型定义
  • 前端：Workspace.tsx、RecordCard.tsx、TextOutputPreview.tsx

2.2 AI 图像生成 已实现

选择图像模型 → 输入正向/反向提示词 → 设置尺寸/数量 → 生成图片。

  • qwen-image-2.0-pro — 千问图像 2.0 Pro（25 分/张，支持 1-6 张批量）
  • qwen-image-max — 千问图像 Max（25 分/张，固定 1 张）
  • 参数：prompt、negative_prompt、size（5 种分辨率）、n、watermark、prompt_extend、seed
  • 前端：ImageOutputPreview.tsx、ImageCostDetail.tsx

2.3 AI 视频生成 已实现

选择视频模型 → 输入提示词/上传首帧/参考图 → 设置分辨率/时长 → 异步生成 → Worker 轮询 → SSE 推送。

  • happyhorse-1.0-t2v — HappyHorse 文生视频（90/160 分/秒）
  • happyhorse-1.0-i2v — HappyHorse 图生视频（首帧驱动）
  • happyhorse-1.0-r2v — HappyHorse 参考生视频（多角色）
  • happyhorse-1.0-video-edit — HappyHorse 视频编辑
  • wan2.7-t2v — 万相 2.7 文生视频（60/100 分/秒）
  • wan2.7-i2v — 万相 2.7 图生视频（首帧/尾帧/续写/驱动音频）
  • wan2.7-r2v — 万相 2.7 参考生视频
  • wan2.7-videoedit — 万相 2.7 视频编辑
  • 独立限流：视频生成 5 次/分钟/用户
  • 异步流程：Server 提交 DashScope → Worker 轮询 → 下载视频+扣款 → SSE 推送
  • 超时处理：>4 小时自动失败+退款
  • 媒体参数上传：首帧图、尾帧图、视频片段、驱动音频
  • 前端：VideoOutputPreview.tsx、VideoCostDetail.tsx、ReferenceMedia.tsx

2.4 生成任务去重 已实现

同参数重复提交自动返回已有记录，避免重复消费。

  • 去重键：accountId + model + hash(parameters)
  • 检查范围：pending / processing 状态的同键记录

2.5 Provider 调用取消 已实现

取消进行中任务，provider 侧 best-effort 取消，支持完整状态追踪。

  • 取消状态流转：not_requested → requested → succeeded / failed
  • 取消后自动退款 + SSE 推送 + 审计日志

4. 字幕处理（Subtitle Pipeline）

4.1 字幕项目全生命周期 已实现

上传视频 → Worker 提取音频 → ASR 转录 → 编辑字幕 → FFmpeg 烧录导出。

  • GET /api/subtitle/projects — 列表

  • 前端：Subtitle.tsx（项目列表）、SubtitleEditor.tsx（编辑器）

  • 导出格式：ASS 字幕（sentencesToAss() from @excuse/subtitle-engine）

7. 计费与成本管理

7.1 信用账户与统计 已实现

  • GET /api/billing/balance — 可用余额 + 冻结金额
  • GET /api/billing/statistics — 30 天费用聚合（按模型/类别/日趋势）
  • GET /api/billing/transactions — 交易流水
  • 前端：Billing.tsx

7.2 Credit Ledger 生命周期 已实现

  • 流程：reserveCredit（预留）→ debitCredit（成功扣款）/ refundCredit（失败退款）
  • 原子操作：SQL WHERE availableCents >= amountCents 防超扣
  • 双扣双退保护：唯一索引 (generationRecordId, type)
  • 审计：每步写入 audit log（credit_reserve / credit_debit / credit_refund）
  • 余额不足通知：notifyInsufficientBalance()（5 分钟冷却）

7.3 费用计算引擎 已实现

  • Token 计费：输入/输出 token × 每百万 token 价格
  • Image 计费：张数 × 单价
  • Video 计费：时长(秒) × 单价（720P/1080P 分别定价）
  • Audio 计费：时长(秒) × 单价
  • 精度：currency.js precision=4，分→元精确转换

7.4 计费策略 已实现

  • workspace.generate — credit-ledger（预留→扣款→退款完整生命周期）
  • openai.gateway.chat — credit-ledger（同上）
  • canvas.pipeline — Beta Free 暂不计费
  • subtitle.asr — Cost-only 仅记录成本，不扣余额

P1 — 上线后尽快解决

P1 Health Readiness / Liveness 探针

当前 /api/health 在 DB 挂了时仍返回 HTTP 200，K8s 无法区分「正常服务」和「DB 挂了但进程活着」。需增加 /health/ready（DB ping 失败 → 503）和 /health/live（始终 200）。

⏱ 半天

P1 Billing 页面展示余额与流水

后端已有 GET /api/billing/balance 和 GET /api/billing/transactions，但前端 Billing.tsx 只展示费用统计，没有展示当前余额和交易流水。

⏱ 半天

P1 CI 流水线补全

CI 只运行 5 个目录的测试，缺失 11 个 packages 的测试 + 构建阶段 + Docker build 验证 + 依赖漏洞扫描。

⏱ 1 天

P1 nginx HTTPS + 上传大小限制

项目自带 nginx.conf 只 listen 80，没有 HTTPS/TLS 配置，没有 client_max_body_size（默认 1MB 限制会阻止大文件上传）。

⏱ 半天

P1 Server 优雅退出机制

Worker 有完整的 SIGTERM/SIGINT 处理，但 Server 没有。K8s 滚动更新时正在处理的 HTTP 请求会直接断开。

⏱ 半天

P1 数据库连接池配置

postgres() 未传入 max/idle_timeout/connect_timeout 参数，水平扩展时 PG 100 连接上限会被快速耗尽。

⏱ 半天

P1 SSE 连接数上限

SSE 端点无最大连接数限制，恶意攻击者可建立数千连接耗尽服务器资源。需设置全局上限和单用户上限。

⏱ 1 天

P1 CORS 生产环境配置

生产环境 CORS origin 硬编码包含 localhost:8007，攻击者可在本地发起跨域请求。

⏱ 半天

P1 OpenAPI 文档生产环境访问保护

/openapi 文档在生产环境中对任何人公开，应添加认证或按环境禁用。

⏱ 半天

P1 上传文件安全校验

仅检查 MIME 类型（来自请求头，可伪造），无文件头魔数校验、无上传频率限制。
